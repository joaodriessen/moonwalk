# How the client fork started

In July 2026, Starlight moved from a separate Moonlight launcher to a fork of
Moonlight Qt. It started from upstream `c0c4d605` with two earlier changes:
a local cursor for absolute mouse mode and a guard for the explicit host
address override. See [Upstream source](../upstream.md) for the original
commit link.

The first interface gave each host a page and kept the existing pairing,
connection, and CLI flows. Local cursor became a saved preference. The initial
address selection work moved a decision previously made by the launcher
into the client itself.

The interface and host policies have changed since then. See
[Architecture](../ARCHITECTURE.md) for the current code and
[per-host settings](2026-07-14-per-host-settings.md) for the migration that
followed.
